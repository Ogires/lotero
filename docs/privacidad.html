Política de privacidad

Última actualización: 23 de octubre de 2026

Lotero es una web que indica si un número de cinco cifras ya ha salido premiado en algún sorteo de la ONCE o de la Lotería Nacional. Esta página explica qué datos trata para hacerlo.

Qué datos se envían

Al pulsar «Comprobar», la página envía el número que has escrito a la API de Lotero (lotero-api.webninja.workers.dev). Es lo único que envía: no hay registro, cuentas ni formularios con datos personales.

Como en cualquier conexión a Internet, la web y la API reciben técnicamente la dirección IP y los datos habituales del navegador (por ejemplo, el user agent). Lotero no los guarda ni los usa para identificarte.

Qué no hace la web

  • No usa cookies ni guarda nada en tu navegador.
  • No incluye analítica, publicidad ni rastreadores.
  • No vende ni gestiona juegos, ni enlaza a operadores de apuestas.
  • No vende ni cede datos a terceros.

Dónde se procesan los datos

La web está alojada en GitHub Pages y la API funciona en Cloudflare Workers. Ambos pueden conservar durante un tiempo limitado registros técnicos de las peticiones (en el caso de la API, incluida la dirección consultada, que contiene el número) para el funcionamiento y la seguridad del servicio. Lotero solo usa los de la API para detectar errores. Consulta las políticas de privacidad de GitHub y de Cloudflare.

Origen de los resultados

Los resultados proceden de la información pública de la ONCE y de Loterías y Apuestas del Estado. Lotero no está afiliada a ninguna de las dos. Comprueba siempre los resultados oficiales.

Cambios y contacto

Si esta política cambia, se actualizará esta página y su fecha. Para cualquier duda, abre una incidencia en github.com/Ogires/lotero. El código fuente de la web y de la API es público en ese repositorio.
